# CC_RC 注册物品规则

仅在注册新物品/方块时阅读本文件。

## 1. 注册前的准备工作

- 调用以前写过的代码前，先查 `DEVELOPMENT_LOG.md` 的「一、目录」索引或「三、注册物品」表格，找到对应类名与文件路径，避免重复造轮子。

## 2. 注册物品/方块时必须同步更新开发日志

修改 `DEVELOPMENT_LOG.md`，规则如下：

1. 在「一、目录」索引表中新增对应行（如新增方块/物品/功能分类）。
2. 若涉及新逻辑，在「二、代码」补充对应章节与关键代码示例。
3. 在「三、注册物品」按方块类归属添加条目，并同步更新各节统计数量（方块/物品/方块实体/声音总数）。
4. 修改/删除已有注册内容时，同样必须同步更新日志对应条目与数量。

## 3. 新增音乐唱片

- 同时更新「三、注册物品 → 2. 物品 → 音乐唱片表」与「三、注册物品 → 4. 声音」两张表。
- 同步更新「三、注册物品」开头的物品总数统计。

## 4. 代码与资源校验

- 新代码必须添加中文注释，注释须与代码真实行为一致；修改逻辑时同步更新受影响注释。
- 修改资源（贴图/模型/blockstate/sound）后，检查对应 JSON 引用是否成对，避免残留未使用文件。
- 修改 Java 源码后，在项目根目录运行 `gradlew build` 验证编译。
