# CC_RC 打包发布流程

仅在打包新版本时阅读本文件。流程如下：

## 1. 更新版本号并打包

- 修改 `gradle.properties` 中 `mod_version=X.Y.Z`。
- 在项目根目录运行 `gradlew build`。
- 产物：`build/libs/cc_rc-X.Y.Z.jar`。

## 2. 同步 GitHub 仓库与开发日志

- 将本周期临时日志内容整理并入 `DEVELOPMENT_LOG.md`（如有新注册/修改内容，参见「注册物品规则.md」）。
- 提交并推送（使用 SSH over 443，命令见下文「推送命令」）。

## 3. 发布 Release

- 用 `gh release create` 发布新版本，Release 说明直接采用本周期临时日志内容：

  gh release create vX.Y.Z build/libs/cc_rc-X.Y.Z.jar --notes "<临时日志内容>"

- gh 位于 `E:\trae\program\CC_RC\.tools\bin\gh.exe`，仓库为 https://github.com/HaiOu-Redstone/CC_RC。

## 4. 归档临时日志

- 将 `临时日志.md` 保存为 `临时日志归档/临时日志-vX.Y.Z.md`。
- 新建空白的 `临时日志.md`（保留说明头）继续记录。

## 推送命令（SSH over 443）

github.com 直连被网络拦截，需走 ssh.github.com:443：

```powershell
$env:Path = "E:\Program Files\Git\cmd;E:\trae\program\CC_RC\.tools\bin;" + $env:Path
$env:GIT_SSH_COMMAND = 'ssh -i "E:\trae\program\CC_RC\.tools\ssh\id_ed25519" -o StrictHostKeyChecking=accept-new -o UserKnownHostsFile="E:\trae\program\CC_RC\.tools\ssh\known_hosts"'
git add -A
git commit -m "描述"
git push origin main
```
