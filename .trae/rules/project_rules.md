# CC_RC 项目规则（常态）

1. **注册新物品**：先读根目录「注册物品规则.md」，再动手注册。
2. **打包模组**：先读根目录「打包发布流程.md」，再执行打包发布。
3. **开发日志**：位于 `DEVELOPMENT_LOG.md`，需要查历史代码/注册信息时可查看。
4. **临时日志**：位于 `临时日志.md`，做任何操作都在其中简要追加记录（只追加不改历史）。
5. **修改代码**：需添加中文注释；修改完成后运行 `gradlew build` 验证编译；并同步更新开发日志「二、代码」对应内容。
6. **修改资源文件**（贴图/模型/blockstate/sound）：检查对应 JSON 引用是否成对，避免错误与残留。
