数字圆盘记录仪（纸带记录仪）—— 框 + 纸 + 刻度板 + 笔
=======================================================
一个灰色外框，内凹一张记录纸（整张纸就是一张平面贴图），
纸的右边是一块固定的刻度板（0~100，每 20 一个数字），最右边立着一支笔。
**模型里没有曲线**：曲线由模组自己渲染，模型只提供一个底座和一支会上下动的笔。

【文件说明】
  recorder.obj        唯一的模型文件，按 o 分成 2 块：
                        Body     外框 + 黑内唇 + 记录纸 + 刻度板（全部静态，合在一起）
                        Pen      笔（只有它动，只在刻度板左缘上下动）
  recorder.png        贴图 512x512（纸面 + 刻度板 + 色块，不透明）
  recorder.mtl        材质，map_Kd 指向 recorder.png
  previews/
    recorder_front.png   正面
    recorder_iso.png     斜视
    recorder_pos.png     笔在 10 / 35 / 60 / 85 四个读数的示意（只是预览图）

【唯一的输入：读数 -> 笔的 Y】
  选中 Pen，只平移 Y，不要动 X / Z。笔的 Y 就是当前读数：
    y = 2.836 + 0.07276 * v
  v=0 在下面、v=100 在上面；可放范围 y = 2.836 ~ 10.112。
  文件里的默认姿态是 v = 50（y = 6.474）。

【接入模组时的约定（重要）】
  · 模组只提供「一个输入」：读数 value（0~100）。
  · value 只驱动 Pen 的 Y，其他一律不动；Body 永远静止（不平移、不缩放、不换贴图）。
  · **曲线由模组自己画**，模型里没有墨带，也不要去改 Body 来"造"曲线。
  · value 要 clamp 到 0~100、NaN 保护、做 200~400ms 平滑；每 tick 更新一次就够。
  · 每帧只改一个变换（Pen 的 Y），不重建网格、不换贴图、不产生垃圾。

【曲线该画在哪（设计单位 u = 1/16 方块）】
  纸面（正面）                z = -2.800
  纸的范围                    x 2.22 ~ 13.78，y 2.22 ~ 10.78
  可画曲线的区域              x 4.0118 ~ 13.78（右边 2.22~4.0118 被刻度板挡住）
  建议曲线所在平面            z = -2.815（比纸面高 0.015，正好是原来墨带的位置）
  曲线右端应该接在            x = 4.0418（笔尖）
  读数换算                    y = 2.836 + 0.07276 * v（和笔完全一样）
  剪裁                        别画到纸外面（至少要限制在框内孔 x 1.80~14.20、y 1.80~11.20）
  纸是静止的，要滚动的话由模组自己的几何/UV 去滚，模型不参与。

【坐标 / 单位】
  · 1 单位 = 1 个方块 / 16；OBJ 里存的是方块（bbox x 0~1.0、y 0~0.8125、z -0.1875~0）
  · 外形 16 x 13 x 3 单位 = 1 方块宽、0.81 高、0.19 厚
  · +Y 向上，正面（纸面）朝 -Z；纸 z = -2.80，刻度板 z = -2.858~-2.836，笔 z = -2.928~-2.828
  · 放进 Blockbench 时导入缩放 x16

【结构（2 个 mesh）】
  Body   合并了：外框（3 单位厚灰板挖空 + 内圈台阶）+ 黑内唇 + 记录纸 + 刻度板（高出台面 0.022）
  Pen    笔：笔尖朝下的三角 + 竖直笔杆（总高约 1.1），立在纸最右边、挨着刻度板

【纸面内容】
  · 米白纸底 + 每 10 一条浅线
  · 中间一条淡绿带（正常区 35~65）
  · 上下各一条红线（限值 87 / 14）
  · 刻度板：每 10 一小格、每 20 一个大格 + 数字（0/20/40/60/80/100），顶 88~100、底 0~12 为红色报警区
  · 没有曲线（曲线是模组画的）

【性能】
  · 212 个三角形（Body 168 + Pen 44）、142 个顶点、2 个 mesh、1 个材质、1 张 512² 贴图
  · 静态件已合并成一个 Body；每帧只有 Pen 的 Y 一个变换
  · 想再省：把笔简化成一个方块即可；贴图还能降到 256²（只影响近景）

【注意】
  · 纸面和刻度板都是整面贴图，其余面是纯色块
  · 没有中文，也没有多余零件
  · png 不透明，未使用 alpha
