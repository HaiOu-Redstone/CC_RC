数字键盘（keypad）—— 外壳 + 屏幕 + 10 个方键 + 2 个圆钮
========================================================
一块 1 方块见方的数字键盘：米黄外壳、深色面板、顶部显示屏、3x4 数字键（1-9 + 0），
右边两个圆形按钮（上面深色、下面红色）。中文标题按要求忽略，只保留数字。

【文件说明】
  keypad.obj          主模型，13 个 group：
                        Body      外壳 + 面板 + 显示屏壳 + 屏幕 + 两个圆钮的圈（全部静态）
                        Key1..Key9, Key0   十个方键（键面数字画在贴图上）
                        BtnTop    上面那个深色圆钮
                        BtnBot    下面那个红色圆钮
  keypad_digits.obj   【可选】四位七段数码管：4 位 x 7 段 = 28 个 group（D1_A ... D4_G）
                      和 keypad.obj 同一套坐标，叠上去正好落在屏幕里
  keypad.png          512x512 贴图（10 个键面 + 屏幕 + 色块，不透明）
  keypad.mtl          材质，map_Kd 指向 keypad.png
  previews/           正面 / 斜视 / 按下+换数字的演示图

【按下（每个键独立）】
  方键：抬起时正面 z = -2.95，按下 z = -2.45，即【沿 +Z 平移 0.50 单位】（往面板里沉）
  圆钮：抬起 z = -2.98，按下 z = -2.62，即【沿 +Z 平移 0.36 单位】
  · 只动 Z，不要动 X / Y
  · 按键沉下去后会露出一圈暗色凹槽（按下状态才生成），所以"按下"看得见
  · 圆钮的圈是真的环，键帽沉进去仍然露在外面

【屏幕数字（两种做法，任选）】
  1) 模组自己画（推荐，和记录仪曲线一样）：
       屏幕矩形 x 3.20 ~ 12.80，y 12.40 ~ 14.30，屏幕玻璃正面 z = -2.975
       数字画在 z = -2.99 ~ -2.98（在玻璃前面、外壳正面 -3.00 后面）
       4 位数字格：格宽 2.40，中心 x = 11.60 / 9.20 / 6.80 / 4.40（x 从大到小 = 屏幕左到右），
                   中心 y = 13.35；单字建议 0.86 宽 x 1.52 高，段粗 0.20
  2) 用附带的 keypad_digits.obj：每位七段都是独立 group，显隐拼数字
       0:ABCDEF 1:BC 2:ABGED 3:ABGCD 4:FGBC 5:AFGCD 6:AFGECD 7:ABC 8:ABCDEFG 9:ABCDFG
       第 1 位（D1_*）在屏幕最左边（x = 11.60）；文件里 28 段全亮（看起来是 8888），
       不需要的段隐藏掉就是你要的数字；想直接固定某个数字，用 build_digits("1234") 重新生成

【坐标 / 单位】
  · OBJ 里坐标以方块为单位（bbox x 0~1、y 0~1、z -0.1875~0）
  · 设计单位 1 u = 1/16 方块 = Blockbench 1 单位；外形 16 x 16 x 3 u = 1 方块见方、0.19 厚
  · +Y 向上，正面（按键面）朝 -Z；导入 Blockbench 缩放 x16

【性能】
  · 主模型约 2100 个三角形、13 个 group、1 个材质、1 张 512² 贴图
  · 每个键按下只有 1 个 Z 变换；不重建网格、不换贴图
  · 如果只是做装饰、不需要按，可以把 Key*/Btn* 并回 Body 再导出，面数不变但组少一点

【注意】
  · 键面数字是画在贴图上的，改数字就改贴图上对应的小方块（k0~k9）
  · 屏幕本身是空的（深色玻璃），不要指望它自带数字——数字是模组画的或数码管叠上去的
  · png 不透明，未使用 alpha
