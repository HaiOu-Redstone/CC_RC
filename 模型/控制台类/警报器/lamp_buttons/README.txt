灯 + 两个按钮 组合体（控制面板零件）
=======================================
一块红色面板，左边一个方形指示灯，中间/右边两个圆形按钮。
共 6 个状态文件，共用同一张贴图和同一个 mtl。

【文件说明】
  lamp_btn_off.obj      灯灭，两个按钮都没按
  lamp_btn_on.obj       灯亮（红色）
  lamp_btn_off_a.obj    灯灭，左边(中间)按钮按下
  lamp_btn_on_a.obj     灯亮，左边(中间)按钮按下
  lamp_btn_off_b.obj    灯灭，右边按钮按下
  lamp_btn_on_b.obj     灯亮，右边按钮按下
  lamp_buttons.png      贴图（RGB，不透明）
  lamp_buttons.mtl      材质，map_Kd 指向 lamp_buttons.png
  previews/             每种状态的正面图 / 斜视图 + 汇总图 all_states.png

【坐标 / 单位】
  · 1 单位 = 1 个方块（和 Minecraft 一致）
  · 外形尺寸 16 x 16 x 3.23 单位 = 1 个方块见方、厚 0.20 方块
  · +Y 向上，正面朝 -Z（装饰面在 -Z 一侧；从 -Z 方向看就是正面图的样子）
  · 放进 Blockbench 时数值 x16 即为其单位（16 单位 = 1 方块）

【做法要点】
  · 全部由长方体 + 八角柱拼成，没有曲面，保持方块风
  · 八角柱 = 两条十字长方体 + 4 条 45 度斜条，正面是平的（所以正面是八角形）
  · 灯亮/灯灭、按钮按下/弹起都是独立 obj，切换状态就是换模型/换部件
  · 按钮按下：圆帽下沉 0.56 单位、直径缩小、颜色加深，并露出一圈暗色内凹环
    —— 正面正交视角下也能一眼看出按进去了
  · 贴图只有纯色块和灯的发光渐变，没有任何文字

【颜色】
  奶油边框 #e2d7bd    深奶油 #c3b599
  红色面板 #b23a2b    顶部黑条 #202024
  指示灯 灭 #4f261f（暗红镜片） / 亮 #c02b1e 带白色高光
  左按钮 深灰 #4e4e57 / #33333a，按下 #33333a / #24242a
  右按钮 暗红 #b8452c / #8a2d1d，按下 #8e2f20 / #62201a
  内凹环 #0e0e11      凹槽底 #101013

【贴图说明】
  · 按面 UV：每个面贴 png 上的一小块纯色（4x4 像素），改颜色只要改对应小方块
  · 色块四周留了 3 像素同色边，线性过滤/多级渐远不会串色
  · 整张 png 不透明，没有用到 alpha
